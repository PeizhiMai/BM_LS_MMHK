# MMHK Overleaf upload bundle

## Upload
1. In Overleaf, choose **New Project > Upload Project**.
2. Upload `MMHK_overleaf_upload_20260803.zip`.
3. Use **pdfLaTeX** and the latest TeX Live version.
4. Confirm that `main.tex` is selected as the Main document.

## Documents
- `main.tex`: current 9-page two-column manuscript (default Main document).
- `supplement.tex`: Supplemental Material. Open it and click Recompile, or select it as the Main document temporarily.
- `significance_statement.tex`: standalone Significance Statement.
- `references.bib`: shared bibliography.
- `figures/`: the five main-text figure PDFs.
- `supp_figures/`: Supplemental Material figure PDFs.

Only manuscript sources and the figure PDFs they actually use are included. Raw data,
analysis scripts, local build products, auxiliary files, and stale manuscript versions
are intentionally excluded.
